# 免费静态版说明

这套免费版已经切换为 `static` 模式，适合部署到纯静态平台：

- GitHub Pages
- Cloudflare Pages
- Netlify

## 免费版保留的能力

- 封面页、密码页、模式页、答题页、结果页
- 结果分享链接
- 同一设备、同一浏览器里的自动续答
- 本机浏览器里生成密码、验证密码、答完后作废

## 免费版必须接受的限制

- 密码只保存在“当前浏览器本地”
- 你在自己的浏览器生成的密码，别人设备上不能直接验证
- 不能实现真正跨设备的一次性密码
- 不能实现真正服务端作废

## 什么时候适合免费版

- 你自己演示
- 同一台设备上测试完整流程
- 先公开页面样式和测试体验
- 暂时不做正式发码运营

## 什么时候不适合免费版

- 你要把密码发给别人，让别人直接在他们设备上测试
- 你要严格控制“一码一人、看完作废”
- 你要长期正式运营

## 如果以后恢复正式版

把 [deployment-config.js](/C:/Users/13922/Documents/Codex/2026-08-03/wo/work/result-template/deployment-config.js) 里的：

```js
mode: "static"
```

改成：

```js
mode: "server"
```

然后再用带后端存储的部署方案。
